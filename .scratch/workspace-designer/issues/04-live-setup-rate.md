# 04 — The price is always on screen

**What to build:** A user never has to reach checkout to find out what something costs. The Setup rate for the current Workspace sits prominently in the builder — "Your setup, $42 per week" — and moves the instant anything is added, removed, or swapped.

Prices are demo values in USD, and every screen showing one says so. Monthly rates beat four weekly cycles, so the longer commitment is visibly worth making.

The Setup rate is computed from the Workspace alone, with no delivery or duration involved, because those don't exist yet — and because that is what makes it a rate rather than a total.
